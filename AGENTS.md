# AGENTS.md

## Проект и ветки

Это личный репозиторий `kompas_auto_draft`. Командный `kompas-drawings` — отдельный
репозиторий; не переносите в него изменения без задачи пользователя.
Перед работой проверяйте `git status` и текущую ветку.

- `master` — общие инструменты, подключение к КОМПАС и личные материалы.
- `ml-system-design` — дизайн-документ и задания по ML System Design.
- `ml-rnd` — эксперименты, оценка, исследования и задания по ML в R&D.
- `hw_1` — сохранённая история первого задания; не менять и не удалять без запроса.

Общие инструменты в учебных ветках наследуются из `master`. Новые общие изменения
переносите отдельными коммитами; учебные ветки целиком в `master` не сливайте.
Подробности — [docs/branches.md](docs/branches.md).

## Сохранность работы

- Не перезаписывайте незакоммиченные изменения пользователя.
- Исходные данные, сырые ответы и завершённые прогоны сохраняются без правок.
- Локальные `runs/`, `vendor/`, `mcp/`, `.mcp.json`, `.codex/` и
  `kompas_data/e2e-*/` не добавляются в публичный Git автоматически.
- Для построителя доступны только входной чертёж и разрешённые инструменты.
  Эталоны, чужие результаты и оценка находятся за пределами его рабочей области.

## Разработка

Python 3.12+, `uv`, Ruff и pre-commit. Перед коммитом —
`uv run pre-commit run --all-files`; в `ml-rnd` также запустите существующие локальные
тесты по её README. Тяжёлые зависимости оценки остаются в отдельном окружении.
Новые функции снабжаются аннотациями типов; запись результатов — через временный файл
и переименование. Не меняйте поведение экспериментального кода в рамках уборки структуры.

Документы — на русском, с коротким разделом «Кратко» в начале. Выводы об опытах
подкрепляйте ссылками на сохранённые результаты. Коммиты — коротко по-русски,
с префиксом `feat:`, `fix:`, `docs:` или `chore:`.

## КОМПАС

Рабочая версия — КОМПАС-3D v25 Study на Windows. Подключайтесь к уже запущенному
экземпляру через `ksapi.GetKompas()`; не запускайте второй. Чужие документы
открывайте копиями. Документы, открытые человеком, не закрывайте и не меняйте.
Пробы выполняются последовательно; успешность экспорта проверяется по самому файлу.
