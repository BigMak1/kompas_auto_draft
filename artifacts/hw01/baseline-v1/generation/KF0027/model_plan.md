# План модели

Кольцо Ø105, толщина 12: blank_profile + extrude blank, параметры outer_d, thickness.
Отверстие Ø65H7: bore_profile + cut bore, параметр bore_d.
Четыре фаски 0,5×45°: отдельные outer_chamfer и bore_chamfer на торцевых кромках, параметр edge_chamfer.
Крепёжные отверстия Ø8,4 насквозь и цековки Ø14 глубиной 8: отдельные круговые cut bolt_a, counterbore_a и bolt_b, counterbore_b. Центры на Ø85. Параметры bolt_d, counterbore_d, counterbore_depth, pitch_d.
Повторы: circular_pattern bolt_pair_a, 2 экземпляра на угле 90° (90°,180°), и bolt_pair_b, 2 по кругу (135°,315°). Параметры количества и угла.
Штифтовые отверстия Ø8H7: отдельный cut dowel, circular_pattern dowel_pair, 2 по кругу (45°,225°). Параметры dowel_d, dowel_count, pitch_d.

Порядок: заготовка → центральное отверстие → фаски → крепёжные отверстия с массивами → штифтовые отверстия с массивом.
Простые эскизы constrain:true; bindings добавляются после диагностики реальных размеров и параметров.

Допущения: четыре фаски на наружных и внутренних торцевых кромках по разрезу; углы части отверстий определены по графике. Все малые отверстия сквозные; цековки с плоским дном со стороны Z=0, материал занимает Z=0…12. Номинальные размеры без моделирования допусков и шероховатости. Пазов и скруглений нет.
Параметрические ограничения: начальные выражения координат не заменяют bindings. Проверять параметры, отклонённые ограничения и unused_variables. Изменение и перестроение готовой M3D через этот API не проверяется.
