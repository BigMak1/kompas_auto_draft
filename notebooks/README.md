# EDA учебного набора

## Кратко

[hw01_eda.ipynb](hw01_eda.ipynb) содержит выполненный анализ данных с таблицами,
чертежами и графиками. Сводка описывает исходный корпус, подробные измерения —
опубликованный набор dev/val. КОМПАС, SSH и доступ к модели не нужны.

## Запуск

Из корня репозитория:

```bash
uv sync --project notebooks --locked
uv run --project notebooks --locked jupyter lab notebooks/hw01_eda.ipynb
```

В Jupyter выбрать ядро Python из окружения `notebooks/.venv` и выполнить **Restart Kernel
and Run All Cells**. Ноутбук находит данные и при запуске из корня репозитория,
и при запуске из `notebooks/`.

Повтор без браузера в свежем ядре, с сохранением выполненных ячеек:

```bash
uv run --project notebooks --locked python notebooks/execute.py
```

Для сохранения отдельной копии добавить `--output /path/to/eda.ipynb`.
Окружение имеет собственные `pyproject.toml` и `uv.lock`; зависимости замороженного
эксперимента в корне не изменяются. Первая установка требует реестра пакетов,
сам анализ читает только файлы репозитория.

## Источники и границы

Источники: [манифест набора](../data/hw01/v1/manifest.json), его SHA256, PNG и
сохранённые проверки пар в `data/hw01/v1/qa/`. Ноутбук не обращается к закрытому
локальному корпусу и не считает подробные характеристики отсутствующих в поставке файлов.
Отсутствие точных дубликатов не доказывает отсутствие близких вариантов или утечек
из предобучения. Анализ добавлен после baseline; его результаты не использовались
для изменения сдаваемого опыта.

Выполнение использует [nbclient](https://nbclient.readthedocs.io/en/latest/client.html),
окружением управляет [uv](https://docs.astral.sh/uv/concepts/projects/run/).
