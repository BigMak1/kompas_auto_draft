# Анализ набора «чертёж — модель»

## Кратко

[Ноутбук](EDA.ipynb) исследует выбранные 10 пар как единый набор:
общая галерея чертежей 4–4–2, разрешение и заполнение изображений,
галерея STL, размеры и целостность сеток, расхождения исходных пар.
Все детали относятся к валидации. Здесь нет результатов генератора или его оценки.
Таблицы, изображения и выводы сохранены в ноутбуке; интерактивные виджеты не используются.

## Окружение

У проекта два отдельных окружения на Python 3.12:

| Проект | Окружение | Назначение |
|---|---|---|
| `kompas_auto_draft` | `.venv` в корне | Агент, построение baseline и оценка |
| `kompas-hw01-eda` | `notebooks/.venv` | Jupyter и анализ данных |

Зависимости EDA закреплены в [pyproject.toml](pyproject.toml) и [uv.lock](uv.lock).
Команды ниже используют отдельное окружение ноутбука.

## Запуск

**Из корня** репозитория установите зависимости и зарегистрируйте ядро в созданном окружении:

```bash
uv sync --project notebooks --locked
uv run --project notebooks --locked python -m ipykernel install --sys-prefix --name kompas-eda --display-name "EDA и 3D (Python 3.12)"
```

Если нет VS code, то можно поднять свой Jupyter Lab сервер на localhost:
```bash
uv run --project notebooks --locked jupyter lab notebooks/EDA.ipynb
```

Выберите ядро **«EDA и 3D (Python 3.12)»** и выполните все ячейки.
В VS Code можно выбрать Python из `notebooks/.venv` в меню выбора ядра.

## Данные

Ноутбук использует [чертежи PNG](../data/input), [эталонные STL](../data/target)
и [манифест](../data/manifest.json) с происхождением файлов и замечаниями к парам.
Размеры изображений и свойства сеток вычисляются из самих файлов.
Для анализа достаточно содержимого репозитория; КОМПАС и ключ API не нужны.
