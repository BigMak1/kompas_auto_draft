# Снимок общего оценщика

## Кратко

`geometry/` — неизменённый снимок оценщика из `kompas-drawings`, протокол cad-eval-0.2.0.
Файлы, ревизия и контрольные суммы перечислены в [SOURCE.json](SOURCE.json).
ДЗ использует этот код через `python -m harness.coursework evaluate`.

Снимок не обновляется автоматически. Документы внутри `geometry/` сохраняют контекст
исходного репозитория; команды для автономного учебного комплекта находятся в корневом README.
Для работы на Windows используется однофайловая `vendor/kompas_lib/kompas_lib.py` той же
версии. Сами KsAPI и КОМПАС в поставку не входят.

Офлайн-режим работает по сохранённым сеткам, измерениям и ответам пересечения.
Хеши экспортёра и библиотеки проверяются при чтении манифестов выгрузки.
Настройки тяжёлых зависимостей находятся в группе `eval` корневого pyproject.toml.
