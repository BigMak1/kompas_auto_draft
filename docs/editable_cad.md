# Редактируемая модель и параметрический MCP

## Кратко

Мост умеет создавать управляющие размеры и именованные переменные, сохранять их связи
в M3D. Новый запуск KF0011 требует понятного дерева операций и проверяемых параметров.

Ссылки на `runs/`, исходные данные и результаты относятся к локальной рабочей копии;
эти файлы не входят в Git. См. [правила хранения](branches.md).

## Возможности

Контракт [API v2](../harness/prompts/api_v2.md) расширен без исполнения кода агента:

- `variables` объявляет переменные детали, включая зависимые выражения;
- `constrain: true` создаёт размеры и геометрические связи простого эскиза;
- `bindings` связывает принятые размеры эскиза и настоящие параметры операций с переменными;
- `parametric` в ответе показывает параметры CAD, формулы, определённость эскизов и неиспользуемые переменные.

Арифметика ограничена числами, известными именами, скобками и `+ - * /`.
Проверка выполняется до подключения к КОМПАС. Пути, открытие чужих моделей и произвольный
Python не добавлены. Вендорная библиотека осталась без изменений.

Выражение в координатах JSON вычисляет начальную форму. Устойчивую связь внутри M3D создаёт
`bindings`; одной переменной в JSON недостаточно. Селектор `dN` относится к принятому
авторазмеру конкретного эскиза, а селектор операции берётся из реальных параметров КОМПАС.
Начальное значение привязываемого параметра должно совпасть со значением выражения.

## Требования к модели агента

[Инструкция v2](../harness/prompts/editable_builder_v2.md) требует отдельные операции для
отверстий, пазов, фасок, скруглений и повторов. Основные размеры должны быть доступны
через переменные или параметры CAD. Нужны план дерева и таблица «что изменить в КОМПАС».

Для функционально сложного профиля допустим отдельный расчётный эскиз. Агент обязан
обозначить, какие его размеры изменяются в CAD, а какие требуют повторной генерации.
Число эскизов и точное совпадение дерева с эталоном сами по себе не служат оценкой качества.

## Ограничения

Автоограничения предназначены для простых эскизов; допустимую сложность задаёт API.
Произвольный ручной набор геометрических ограничений пока не предоставлен.
Полная определённость эскиза и наличие формул не гарантируют устойчивости всех изменений.
Редактирование фасок, скруглений, вращения и массива через новые привязки отдельно в этой
серии проб не проверялось: их реальные параметры возвращаются агенту для настройки.
Выбор рёбер пока выполняется по индексам текущей геометрии.

Изменение числа зубьев само по себе не пересчитывает координатный профиль зуба.
Растровый экспорт через библиотеку в пробе шайбы вернул `preview_error`; M3D и проверка
параметров выполнены успешно, наличие preview не гарантируется.

## Оценка конечной редактируемости

После генерации KF0011 оценщик открывает копию результата и меняет геометрически допустимые
параметры. Проверяются перестроение без ошибок, правильный новый размер, сохранение
независимых элементов и требуемые изменения зависимых. Это оценка конечного M3D,
совместимая с end-to-end постановкой. Геометрическое сходство оценивается отдельно.
Сценарии для окончательной KF0011 ещё не выполнены: новый запуск только подготовлен.
