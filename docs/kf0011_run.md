# Запуск KF0011 с редактируемыми размерами

## Кратко

Подготовлен `runs/e2e/kf0011-codex-003`: тот же исходный PNG, расширенный MCP и инструкция
по параметрическому построению. Сам агент ещё не запускался.

Ссылки на `runs/`, исходные данные и результаты относятся к локальной рабочей копии;
эти файлы не входят в Git. См. [правила хранения](branches.md).

## Запуск оператором

Из корня `kompas_auto_draft` в доверенном терминале Mac:

```bash
.venv/bin/python -m harness.run preflight --run runs/e2e/kf0011-codex-003
.venv/bin/python -m harness.run native-check --run runs/e2e/kf0011-codex-003
.venv/bin/python -m harness.run launch --run runs/e2e/kf0011-codex-003 --model <model-id>
```

Последняя команда запускает генерацию и требует точный идентификатор выбранной модели.
`preflight` проверяет изоляцию без обращения к GPT. `native-check` только подключается
к уже открытому КОМПАС-3D v25 Study. `launch` повторяет проверки и создаёт свежую сессию
Codex без истории этого чата; PNG передаётся через `--image`.

MCP запускаются клиентом с подготовленной конфигурацией. Сам построитель работает без
произвольного SSH и сети. Настройки `.codex/config.toml` обоих подключённых репозиториев
также направлены на новый run. Для ручного чата нужно перезапустить MCP/переподключить
сессию, чтобы не остался сервер старого запуска. Ручной чат без проверенной песочницы
не считается изолированным benchmark; для эксперимента используйте команду выше.

## Комплект

В [папке запуска](../runs/e2e/kf0011-codex-003/START.md) находятся инструкция оператору,
манифест и доверенные настройки. Агент видит только `builder`: PNG, общие инструкции,
библиотеку и пустую рабочую папку `work`. Эталоны, CDW, предыдущие решения, отчёты сравнения
и данные живых проб туда не перенесены.

[AGENTS.md](../runs/e2e/kf0011-codex-003/builder/AGENTS.md) требует отдельные конструктивные
операции, управляющие размеры и переменные. [API.md](../runs/e2e/kf0011-codex-003/builder/API.md)
описывает `variables`, `constrain` и `bindings`; [CONNECTION.md](
../runs/e2e/kf0011-codex-003/builder/CONNECTION.md) — порядок работы с MCP.

Изоляция проверяет запрет чтения референса, предыдущей M3D, соседних каталогов и второго
репозитория, обхода через симлинк и прямой сети. Результаты — [isolation-check.json](
../runs/e2e/kf0011-codex-003/control/isolation-check.json). Подключение к Windows —
[native-preflight.json](../runs/e2e/kf0011-codex-003/control/native-preflight.json).

Мост разрешает только новую собственную деталь. Он не принимает код или пути от агента.
КОМПАС должен быть открыт в одном экземпляре; одновременно не выполняются другие пробы.
При неопределённом исходе удалённого вызова мост блокирует новые попытки до проверки оператором.

## Повторяемость

Хеши PNG, инструкции и доверенного кода сохранены в `manifest.json` и `control/bundle.json`.
Изменение комплекта требует осознанного `seal` до начала работы и повторной проверки.
Команда не разрешает переподписывать или перезапускать run с уже выполненными попытками,
включая ручные. Новые эксперименты создаются в новых папках:

```bash
.venv/bin/python -m harness.run prepare --run runs/e2e/kf0011-codex-004 \
  --settings runs/e2e/kf0011-codex-003/control/settings.json
```

После `finish` результат появится в `artifacts/model.m3d`, попытки — в `raw`, рецепт и
объяснения агента — в `builder/work`. Оценка выполняется отдельно, на копиях.

Предыдущий [kf0011-codex-001](../runs/e2e/kf0011-codex-001/evaluation/comparison-001/report.md)
сохранён как история первоначального опыта. При оценке новой генерации нужно учитывать
[замечание к исходному референсу](../kompas_data/e2e-27-v1/qa/KF0011.md); построителю оно не передаётся.

Запуск 002 остановился до CAD из-за политики подтверждений MCP. Исправление для 003 описано в [служебной записи](../runs/e2e/kf0011-codex-003/control/mcp-authorization.md).
