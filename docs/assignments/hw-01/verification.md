# Проверка сдаваемого комплекта

## Кратко

7 ноября 2026 года оценка повторена в отдельной чистой копии файлов из индекса Git
с новым виртуальным окружением. IoU и F-score обеих деталей совпали с исходной оценкой
без расхождения. Контрольные суммы и результаты — в [verification.json](verification.json).

## Условия

Проверено на macOS arm64, Python 3.14.5; установлены зависимости из `uv.lock` через
`uv sync --locked --group eval`. В копии отсутствовали локальные прогоны, настройки
подключения и соседний `kompas-drawings`.

Команда преподавателя `uv run --offline --locked --group eval python -m harness.coursework evaluate`
завершилась успешно. Дополнительный повтор последнего публичного комплекта выполнен
с запретом `WorkerClient.invoke`, `subprocess.Popen` и `socket.create_connection`
через `unittest.mock.patch`: оценка также завершилась без обращения к этим функциям.

Это повтор поверхностной оценки и расчёта IoU по сохранённым ответам КОМПАС.
Само нативное пересечение и генерация модели в этой проверке не повторялись.
Численный допуск сравнения — `abs_tol=rel_tol=1e-6`; фактическая максимальная разница — 0.
Проверка на другой операционной системе не проводилась.
