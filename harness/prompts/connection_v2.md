# Подключение к КОМПАС в этом запуске

## Кратко

Для построения нужны настоящие MCP-инструменты чата: `ksapi-expert` и `kompas-builder`.
Файл с настройками сам по себе не подключает инструменты к уже открытому чату.

## Инструкция агенту

1. Найди в доступных инструментах серверы `ksapi-expert` и `kompas-builder`.
   У клиента имена могут иметь префикс пространства имён.
2. Вызови `ksapi-expert.search` с `{"query":"переменные детали","top_k":1}` — проверка документации.
3. Вызови `kompas-builder.health` с `{}` — это проверка SSH, Python и уже запущенного КОМПАС.
   Она не создаёт и не открывает CAD-документы. Ожидается `status: read_only_preflight_passed`
   и `build_quarantined: false`, а также `recipe_version: 2`.
4. После успешных проверок можно передавать свой рецепт в `build`, затем выбрать результат
   через `finish`, как описано в `API.md`. Свой окончательный рецепт сохрани в `work/recipe.json`.

Если инструментов нет, сообщи: «Нужно переподключить MCP в настройках Codex этого проекта».
Не заменяй MCP ручным запуском Python-клиента, `builder_mcp.py` или SSH из shell-инструмента.
Этот процесс наследует сетевой запрет песочницы, поэтому `ssh` получает
`Operation not permitted`. Такая ошибка не означает неверный пароль или путь Python.
Не меняй профиль изоляции и не запрашивай себе произвольный доступ к Windows.

Если health сообщает, что КОМПАС не запущен, попроси открыть КОМПАС-3D v25 Study.
Если `build_quarantined: true`, нужна проверка оператором; самостоятельно не удаляй блокировку.
Диагностика и просмотр входа остаются доступны во время блокировки построения.

## Как соединение устроено

```text
MCP-клиент Codex → доверенный kompas-builder → SSH windows_server → Python/KsAPI → КОМПАС
MCP-клиент Codex → ksapi-expert → документация KsAPI
```

SSH выполняет доверенный мост, а не терминальная команда агента. Мост знает адрес и пути,
читает ключи из стандартной SSH-конфигурации Mac и разрешает только предусмотренные
операции над собственной новой деталью. Пути к эталонам ему передать нельзя.

## Для оператора

Настройки серверов зарегистрированы в `.codex/config.toml` обоих проектов:
`kompas-drawings` (ASKON, где открыт текущий чат) и `kompas_auto_draft`.
В Codex: Settings → MCP servers → Restart; затем `/mcp` для проверки списка серверов.
Если текущая сессия не обновляет каталог, переподключить её после сохранения настроек.
Наличие записи в `codex mcp list` подтверждает конфигурацию; реальное подключение
подтверждают вызовы `sources` и `health`.

`control/codex-config.json` — параметры отдельного CLI-запуска, а не автоматически
загружаемый конфиг настольного чата. `.mcp.json` в этом репозитории предназначен для Claude Code.

Обычный чат с просьбой «работай в папке» не включает файловую изоляцию сам по себе.
Для формального end-to-end эксперимента нужен запуск через `harness.run launch` из доверенного
терминала Mac с проверенным профилем. Ручная сессия пригодна для отладки подключения;
не выдавать её за подтверждённый изолированный benchmark.
